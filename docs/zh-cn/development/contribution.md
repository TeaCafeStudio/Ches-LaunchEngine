# 贡献指南

- 维护共享 Core/SDK 边界；Core 不得依赖终端，也不要复制启动、下载或进程管理器。
- 文档和示例必须与真实 JSON 标签、参数和注册命令一致；规划功能须明确标记为未实现。
- 不要把凭据加入普通 JSON 配置、测试、日志或示例。
- 为行为变更添加针对性测试，并维持跨平台编译。

提交前运行：

```sh
gofmt -w cmd internal pkg
go test ./...
go vet ./...
```

涉及可执行程序或平台差异的改动，还应运行[构建文档](build.md)中的两个矩阵脚本。若环境提供 CGO 和 C 编译器，建议运行 Race 测试。
