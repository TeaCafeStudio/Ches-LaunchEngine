# 貢獻指南

- 維持共用 Core/SDK 邊界；Core 不得相依於終端機，也不要複製啟動、下載或處理程序管理器。
- 文件和範例必須符合實際 JSON 標籤、參數和已註冊命令；規劃中的功能必須明確標示為尚未實作。
- 請勿將憑證加入一般 JSON 設定、測試、記錄或範例。
- 為行為變更新增目標明確的測試，並維持跨平台編譯。

提交前請執行：

```sh
gofmt -w cmd internal pkg
go test ./...
go vet ./...
```

若改動涉及可執行程式或平台差異，也應執行[建置文件](build.md)中的兩個矩陣指令碼。若環境提供 CGO 和 C 編譯器，建議執行 Race 測試。
